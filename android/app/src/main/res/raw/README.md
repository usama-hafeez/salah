# Azaan Audio Files

Place the following MP3 files in this directory for Azaan notification sounds:

- `azaan_mecca.mp3`
- `azaan_egypt.mp3`
- `azaan_pakistan.mp3`
- `azaan_turkey.mp3`
- `azaan_short.mp3`

These files are referenced by `NotificationService` via `RawResourceAndroidNotificationSound`.
If missing, Android falls back to the default notification sound.
